# Todo List Manager with Gradio

A simple web-based todo list manager built with Gradio and Python.

## How to run

python todo_gradio.py

## Features

- Add a todo
- Delete a todo by index
- Numbered todo list

## Requirements

- Python 3.8+
- gradio

You can install Gradio with:

pip install gradio


## Usage

1. Run the app:
    ```
    python todo_gradio.py
    ```
2. The app will open in your web browser.
3. Add or delete todos using the web interface.
